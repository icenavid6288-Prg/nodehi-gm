# فروشگاه اینترنتی لوازم خانگی نودهی (React + TypeScript & Laravel 12 + MongoDB / NoSQL)

این پروژه به صورت **کاملاً مستقل و بدون هیچ‌گونه وابستگی به Next.js یا Prisma** بر پایه معماری زیر طراحی شده است:

- **فرانت‌اند:** `React 18 + TypeScript + Vite + Tailwind CSS` (در مسیر `/src` و `/frontend`)
- **بک‌اند:** `Laravel 12 (PHP)` (در مسیر `/backend`)
- **دیتابیس:** موتور سندگرای **MongoDB / NoSQL Document Store** (`backend/database/mongodb/*.json` + پشتیبانی از اتصال `MONGODB_URI`) که بدون نیاز به دسترسی ترمینال یا SSH روی هاست اشتراکی سی‌پنل (مانند پارس‌پک) کار می‌کند.

---

## ویژگی‌های کلیدی

1. **بدون نیاز به ترمینال و SSH روی هاست سی‌پنل:**
   - دیتابیس سندگرای توکار (MongoDB-compatible JSON Document Collections در مسیر `backend/database/mongodb/*.json`) از پیش با ۲۳ محصول، ۸ دسته‌بندی، ۹ برند، ۵ کد تخفیف، مقالات و تنظیمات مقداردهی شده است.
   - اسکریپت نصب گرافیکی `install.php` برای تنظیم شماره موبایل مدیر کل، نام فروشگاه و رشته اتصال MongoDB از طریق مرورگر.
2. **استودیو طراحی ظاهر در پنل مدیریت (`/admin?tab=appearance`):**
   - آپلود و تغییر لوگوی سایت و شعار برند
   - تغییر رنگ بصری اصلی سایت (Primary / Secondary / Accent) همراه با ۶ پالت رنگی آماده
   - مدیریت کامل اسلایدشو صفحه اصلی با قابلیت آپلود عکس برای هر اسلاید

---

## نحوه نصب روی هاست سی‌پنل (بدون ترمینال)

1. محتویات پوشه `dist-host/public_html` (یا فایل زیپ `nodehi-cpanel-mongodb.zip`) را در `public_html` هاست آپلود و Extract کنید.
2. آدرس `https://your-domain.ir/install.php` را در مرورگر باز کنید.
3. شماره موبایل مدیر کل را ثبت کرده و پس از اتمام، با یک کلیک فایل `install.php` را حذف نمایید.
